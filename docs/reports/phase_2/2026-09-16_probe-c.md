## 1. Purpose (the P-R3 gap) — and what C0 adds

The P-R3 gap: byte 1–4-gram geometry addresses 16/20 domains perfectly but fails on
Latin-script neighbours of early territories (es/pl/sk). The PoC's chat phases are
byte-**identical** with their host corpus, so an input-side router richer than byte counts
is the condition for chat-CL. Sonde C tests the own-AI variant first: a self-distilled head
on BDH early residuals (Arm 1), against an external-embedding upper bound (Arm 2) and a
cheap-first cascade (Arm 3).

**C0 exists because Sonde B exposed a fidelity gap** (B report §6, commit `6f6368d`): B's
base was English-prose-only, which invalidated the planned "family-adjacent to base"
explanation for legal's P-B3 leak. C0 re-runs the B phase set from a **prose+multilingual
base**, so the "family-adjacent" hypothesis is tested on a base that actually contains a
second language, and so Arm 1's residual labels come from a model whose base is not
monolingual.

## 2. Design as run (C0)

- **Base spec:** `prose:data/textmix/wikitext-103-raw/wiki.train.raw,de:data/textmix/files/de45.txt,wikide:data/textmix/files/wiki45.txt`
  (~630 MB; `parl45.txt` excluded as unverified/possible-Europarl contamination per plan).
  mult 128, block 512, batch 4, 150k steps.
- **4 CL phases** (identical to Sonde B): code → math → legal (prose-2, hard case) → ga
  (control). Per phase: 10k steps, batch 1, route-aware α=0.9, grow +32, fresh optimizer,
  `--no-freeze-attn`, F-V9 step-end restore. Width ladder 128→160→192→224→256.
- **Instruments run inside C0:** P5 in-chain (4 transitions), routing confusion (5 domains,
  200 crops, window 128), legal depth (200 crops).

### 3.4 Legal depth — 198/200 (the load-bearing comparison)

`--crops 200 --window 128 --domains legal` on the final checkpoint:

| true\\routed | 8192 | 10240 | 12288 | 14336 | 16384 |
|---|---|---|---|---|---|
| legal | 1 | 1 | 0 | **198** | 0 |

Both misses land on **Latin-script neighbours** (prose, code); none on math or ga.

**Headline finding:** Sonde B (prose-only base) leaked legal **197/200**; Sonde C0
(multilingual base) leaks **198/200**. The multilingual base did **not** close the leak.
→ **The legal leak is byte-geometry-intrinsic, not base-composition-induced.** This closes
the §6 open question from the Sonde B report and confirms Sonde C's premise independently
of the base: the moment a domain is Latin-script-overlapping with an earlier territory,
routing starts to fail, regardless of what the base was trained on. That is exactly the
non-distinctness regime Sonde C exists to resolve.

  stage-2 routing.

  (lv/ga/zh/ja/hi/iu artifacts on .200); two-axis reject still separates.

(§3.4), Arm 1's hard cells are the *right* test targets — the leak is not an artefact of a
weak base that a better base would fix. The C0 label set is therefore a valid distillation
source, and no re-ladder is needed before Arms 1–3.
